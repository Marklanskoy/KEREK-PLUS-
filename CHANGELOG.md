# KEREK PLUS 3.6.0 — Motion UI

- Добавлены `motion.js` / `motion.css`: короткие переходы между разделами, появления видимых карточек, фильтры каталога, анимация корзины/избранного, hover-карточки, модальные окна и уведомления.
- Встроенный премиальный splash и пользовательская глянцевая KH из 3.5 сохранены.
- Эффекты не повторяются на каждом `render`, не затрагивают данные, не запускаются при неуспешном добавлении и отключаются в режиме reduced motion.
- Доработан момент перехода из заставки к реальному содержимому после готовности.
- Версия интерфейса 3.6.0, схема `version:32`, тот же адрес PWA и та же база.
- Регрессии: прежние сценарии корзины/Autopilot, бренд-тесты, новая UI-серия движения.

# KEREK PLUS 3.5.0 — Premium Launch Motion

- Глянцевая оранжевая KH-аватарка без старого чёрного фона во всех активных брендовых элементах, favicon и PWA.
- Премиальная CSS-анимация входа: масштаб и появление, световой проход, золотистые кольца, аккуратные частицы и плавный переход к готовой странице.
- Короткое видимое вступление на быстром запуске, ожидание реальной готовности на медленном, без фиктивных процентов.
- Поддержка `prefers-reduced-motion`, исключение зацикливания при ошибке, сохранение данных.
- Данные и схемы корзины не изменены; только брендовые надписи, пути и загрузочный экран.

# KEREK PLUS 3.5.0

## Бренд
- Прежняя рисованная корзина K+ заменена точным пользовательским изображением IMG_2263.jpeg.
- Один набор изображений для шапки, подвала, профиля, лояльности, «О проекте», восстановления, админ-панели, favicon, iOS/PWA и обновления.
- Новые имена файлов иконок для отличия от ресурсов предыдущего выпуска; старые имена заменены совместимыми копиями.
- Исходное изображение сохранено без модификации; SVG — контейнер для того же изображения, не обещание векторной детализации.

## Запуск
- Реальная CSS-анимация кольца и точек вокруг неподвижного знака.
- Окончание при готовности, отсутствие искусственного процента и минимального времени ожидания.
- Обычная навигация не включает заставку повторно.
- Восстановление/ошибки доступны без перекрытия заставкой.
- Учитывается prefers-reduced-motion; анимация удаляется после завершения.
- Без JavaScript видна статическая помощь, не бесконечная загрузка.

## Совместимость
- Прежний путь и ключ базы сохранены; ядро покупок, хранение и Autopilot не изменены.
- Пересобраны CSP и контрольные суммы всех файлов.
- Название PWA — KEREK PLUS, стабильные id/start_url/scope сохранены.
