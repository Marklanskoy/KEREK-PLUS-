# KEREK 3.3.0 — изменения относительно 3.2.0

13 октября 2026 года. Подготовлен локально, не опубликован автоматически.

| Замечание аудита | Исправление | Регрессия |
|---|---|---|
| A1: отмена возвращает старую корзину | Обратное действие для удалённых строк; не трогаются последующие изменения; проверка stock и повторного добавления | Unit + DOM |
| A2: исчезнувший SKU невидим | Сохраняется строка, объяснение блокировки и отдельное удаление | Unit + DOM |
| A3: нельзя уменьшить количество выше stock | Проверка увеличения отделена от уменьшения; действие «Оставить доступное» | DOM |
| A4: рецепт ниже минимума «готов» | Единая orderReadiness; recipe complete отдельно от orderable; явный список для дополнения; всё дома отдельно | Unit + DOM |
| A5: недействительный код подписан «Применён» | Статус по текущему quote, сумма до условия, удаление кода | Unit + DOM |
| A6: теряются поля/отзыв | Ограниченные локальные черновики7дней, правильная дата каждого черновика, сообщения об отказе записи, срок интервала и явное повторное согласие | Unit + DOM |
| A7: нет истории переходов | pushState, popstate, hashchange, восстановление экрана/прокрутки; фильтры остаются состоянием экрана | DOM, настоящий same-document History API Chromium |
| A8: итог и кнопка слишком низко | Фиксированная панель над мобильной навигацией, учёт занимаемой высоты, кнопки44px, переход к форме/ошибке | DOM + визуальная проверка |
| A9: теряется бюджет покупки | Необязательный cartBudget, перенос из Autopilot/рецепта, сравнение полной суммы, подтверждение превышения | DOM |
| A10: теряется фокус | Восстановление активного элемента/выделения, fallback при disabled/удалении, status live region | DOM, не сертификация скринридеров |
| A11: readonly действия активны | Предварительно отключённые записи, понятная причина, явный retry Web Lock с сохранением формы | Unit/model + DOM |

Дополнительно: согласованная сборка static/server3.3.0 и Autopilot2.1.0; обновлённая страница установки; исходная схема32 и ключ базы не менялись; прежняя иконка сохранена. Новый импорт/экспорт охватывает дополнительные черновики, но не согласие на заказ.

Тестовые покупки, выписки и расходы не превращаются в реальные оплаты. Публичный хостинг автоматически не изменялся.
