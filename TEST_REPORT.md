Финальный результат берётся только из полного повторного прогона.

## Новые воспроизведения после исправлений

- Удаление молока → увеличить хлеб → «Вернуть»: хлеб остаётся увеличенным. Добавленная заново та же позиция не перезаписывается. Отмена очистки объединяет отсутствующие строки; повторная отмена не добавляет повторно. Складские ограничения объясняются.
- Удалённый SKU видим и удаляем отдельно, включая корзину только из отсутствующих товаров. Stock4→1 разрешает «−»4→3; кнопка соответствия оставляет1. Нулевая/неактивная позиция тоже может быть исправлена.
- Рецепт с молоком590 и доставкой990 при минимуме товаров1000 не называется заказом готовым к оформлению. Есть явный перенос для дополнения. Проверены отдельный рецепт, всё уже дома и прямой submit формы вопреки disabled кнопке.
- Промокод обновляет состояние после снижения суммы, просроченный код объясняет блокировку, код можно удалить.
- Черновик адреса/комментария/темы отзыва восстанавливается в новом DOM-экземпляре с той же модельной базой. Смена темы не теряет поля. Согласие не импортируется/не восстанавливается после запуска; при смене значимых условий оно сбрасывается с объяснением. Устаревший интервал не выбирается молча.
- Срок черновика7дней проверяется при загрузке, ограничиваются длины и поля. Сохранение одного черновика не освежает срок другого. Ошибка модели записи не стирает текущий ввод и показывается пользователю.
- Экспорт → удаление → импорт восстанавливает новые поля; ключ другого приложения сохраняется. Успешный тестовый заказ очищает checkout draft без повторного захвата завершённой формы.
- Back/Forward и прямой hash переход работают на History API Chromium. Возврат с карточки товара сохраняет прокрутку длинной корзины.
- Повторное Enter на количестве работает; достижение stock не сбрасывает фокус на BODY. Новый итог объявляется отдельным status элементом. Контрольные зоны кнопок44px.
- Вторая модельная вкладка отключает изменение. Явный повторный запрос блокировки после освобождения разрешает запись и сохраняет введённый текст формы.
- Лимит покупки сравнивается с полной суммой; превышение требует подтверждения. Отмена диалога не создаёт заказ. Бюджет Autopilot переносится в корзину; без явного выбора произвольного ориентира нет.

## Внешний вид

Главная корзина проверена на320/390/768/1440px в светлой и тёмной теме. Тесты проверяют отсутствие горизонтального переполнения и положение закреплённой панели выше нижнего меню. Скриншоты — `evidence/cart33/`. В них только тестовые суммы и иллюстративные заглушки товаров; новая иконка K берётся из локального файла.

Это не полный WCAG-аудит всех экранов, не сертификация контраста и не тест VoiceOver. Настоящая клавиатура iPhone/Android и safe-area на физическом устройстве требуют отдельной проверки.

## Что именно подменяет DOM-стенд

HTML загружается через `set_content`. Только в тестовый экземпляр вставлены Map-модели localStorage/sessionStorage и Web Locks. Сетевые запросы, включая фотографии, отключены. CSP удалён только из тестового HTML для вставки стенда; CSP готового выпуска с точным SHA256 скрипта сохранён и проверен отдельными тестами. Back/Forward используют настоящий same-document History API на тестовой странице, а не настоящее открытие публичного сайта.

Модельные два клиента не доказывают native конкуренцию Web Locks. Перезапуск DOM с тем же словарём не равен закрытию/открытию Safari на устройстве. В Python-тестах API и SQLite реальны, но вызываются внутри процесса без развёртывания HTTP.

## Не проверено / не подключено

Native localStorage/Web Locks, service worker/офлайн-установка PWA, Safari/Android на устройстве, Docker-сборка, внешняя банковская оплата, SMS, реальная доставка, актуальный склад и модель ИИ не проверены. Соответствующие интеграции отсутствуют. Полный аудит безопасности, нагрузки и всех конкурентных серверных действий не проводился.

Срок7дней ограничивает восстановление черновика при загрузке, а не гарантирует физическое удаление всех копий в определённый момент. Данные и JSON не зашифрованы. Оригинальные локальные/скачанные резервные копии требуют отдельного управления.

## Перед использованием на устройстве

Сохранить внешний JSON. Загрузить полный комплект на прежний адрес. Закрыть старые вкладки, открыть страницу обновления. Сверить избранное/корзину/расходы. Внести тестовую строку, закрыть и открыть приложение, проверить сохранение. Проверить второй таб и повторное получение редактирования. В отдельном тестовом профиле проверить экспорт/импорт. После онлайн-запуска проверить офлайн без удаления пользовательской базы.

Реальное оформление заказа у магазина не включается загрузкой этого архива. Тестовое подтверждение не списывает деньги.
