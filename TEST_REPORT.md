## Поведение новой анимации

- Эффекты реализованы отдельными `motion.js` и `motion.css`; сервис не делает сетевых запросов и не меняет сохранённые суммы или товары.
- Полная анимация перехода выполняется **только при смене раздела**, а не при каждом изменении количества/корзины. Для корзины применён opacity-only переход, чтобы `position:fixed` панели итогов не менялся из-за трансформации родителя.
- Успешное добавление товара визуально подтверждается после сравнения старого и нового количества; ошибочный клик не должен рисовать ложное подтверждение. Лёгкая частица исчезает самостоятельно после анимации.
- Сохранение в избранное и обновление каталожной сортировки запускают короткие эффекты.
- Hover-эффекты включаются только при `(hover:hover) and (pointer:fine)`; для смартфонов не применяются.
- Анимации переходов используют свойства `opacity/transform`, без перезаписи стилей реальных данных; эффекты диалогов и уведомлений не блокируют ввод и подтверждение.
- При системном `prefers-reduced-motion: reduce` декоративные эффекты JS отключены, CSS-анимации/переходы сведены к минимуму, приложение продолжает работать.
- У старой базы сохраняется тот же ключ и схема `version:32`; миграция и содержимое JSON ради анимации не менялись.

## Ограничения

- **Это тестирование в Chromium с явно подставленной моделью `localStorage`, `sessionStorage` и Web Locks.** Native iOS Safari/Android, настоящие Web Locks, нативный Service Worker, PWA и офлайн-перезапуск не проверены.
- Сеть и фотографии товаров в модельном стенде отключены. Заглушки не доказывают, что настоящие фотографии недоступны на опубликованном сайте.
- Публикация GitHub Pages после загрузки архива, работа на конкретном iPhone, серверный деплой, производительность на маломощных устройствах и полная проверка скринридеров — отдельные задачи.
- Крупные изменения каталога, реальная оплата, SMS, курьеры, AI и синхронизация устройств не являются частью данного релиза. Магазин остаётся демонстрационным.
- Анимация не защищает данные от очистки браузера: до обновления сделайте отдельную JSON-копию и не публикуйте её на GitHub.

## Что проверить после загрузки на iPhone

В том же браузере: сохранить резервную копию → загрузить файлы → открыть `update.html` → сверить корзину → добавить товар → открыть корзину → вернуться «Назад» → обновить страницу и проверить сохранение → проверить в iOS «Настройки → Универсальный доступ → Движение → Уменьшение движения». Установленную PWA проверять только после сохранения копии. Не очищать Safari ради обновления иконки.
