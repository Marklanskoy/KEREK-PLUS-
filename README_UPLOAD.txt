KEREK PLUS 3.5.0 — Премиальная анимация входа

1. Откройте текущий KEREK: Профиль → Настройки → Экспорт JSON. Сохраните копию на устройстве.
2. Распакуйте архив KEREK_PLUS_3_5_Update.zip.
3. В репозитории https://github.com/Marklanskoy/KEREK-PLUS- выберите Add file → Upload files.
4. Загрузите ФАЙЛЫ ИЗ АРХИВА в КОРЕНЬ репозитория. Не загружайте сам ZIP и не создавайте внешнюю папку.
5. Commit changes → дождаться успешного GitHub Pages deployment.
6. В прежнем браузере открыть https://marklanskoy.github.io/KEREK-PLUS-/update.html
7. Нажать «Сохранить копию перед обновлением», затем «Открыть KEREK PLUS 3.5.0».

Не загружайте личные JSON на публичный GitHub. Не очищайте данные Safari.
GitHub доступен на чтение — этот архив не установлен автоматически.
